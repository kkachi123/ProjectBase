# 맵 조합 진행 현황

이 문서는 맵 조합의 구현과 검증 범위를 기록한다. 전체 진행은 [맵 작업 진행 현황](../Map_Progress.md), 코드와 사용 방법은 [맵 조합 코드 구조](Map_Assembly_Code_Guide.md)와 [맵 연결 계획](Map_Planning_Guide.md)을 참고한다.

## 완료한 기본 단계

- [x] **경로와 방 선택:** seed를 사용해 격자의 시작부터 Goal까지 좌우·하강 경로를 정하고 출입구·통과 조건이 맞는 템플릿을 선택한다. 경로 밖은 닫힌 방으로 채운다.
- [x] **계획 검증과 실패 처리:** 연결·마커·제작 데이터 등을 검사하고, 후보가 없으면 제한된 횟수까지 다시 계획한 뒤 사유를 반환한다. 동일 설정과 seed의 계획 재현을 지원한다.
- [x] **씬 생성과 에디터 미리보기:** 검증한 계획으로 방과 Goal을 생성한다. 미리보기는 공통 생성 흐름과 Undo·Redo를 사용하며 생성 실패 시 기존 결과를 보존한다.
- [x] **Run 연결:** 생성 결과의 시작·Goal 위치를 Run과 연결하고, 새 맵을 성공적으로 생성한 후 기존 맵을 교체한다.
- [x] **선택 방 연결:** 검증된 분기와 막다른 방이 있으면 주 경로에 최대 하나 연결한다. 후보가 없으면 선택 방 없이 생성한다.
- [x] **이전 생성기 정리:** 이전 생성기·DB와 방향별 청크 프리팹을 정리하고 일부 지형을 새 템플릿과 패턴 후보로 전환했다. 관련 결과는 [작업 이력](../Map_Refactoring_Log.md#방-템플릿-기반-맵-생성-전환)에 있다.

## 검증 범위와 이후 확인

- 자동 검사에는 기본 설정의 seed 0~999 계획 불변 조건과 생성·실패 처리, 미리보기 검증이 포함된다. 테스트 위치는 [맵 조합 코드 구조](Map_Assembly_Code_Guide.md#코드와-테스트-읽는-순서)를 참고한다.
- 작업 당시 샘플의 17개 통과 방향과 대표 seed의 시작부터 Goal·타이틀 복귀를 실제 Player로 확인했다. 이는 당시 사용한 템플릿과 설정에 대한 결과다.
- 방의 지형·Collider·통로가 바뀌면 관련 검증 표시를 해제하고 해당 연결을 다시 확인한다. 템플릿·카탈로그 정리 후 참조와 대표 seed 생성 결과는 [Chunk 내부 생성 진행 현황](../Chunk_Generation/Chunk_Generation_Progress.md)에서 확인한다.
