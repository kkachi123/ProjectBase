# 방 지형 타일과 그래픽 제작 계획

## 목표

방 템플릿에 사용할 지형 타일과 배치 규칙을 정하고, 대표 방에서 방 내부와 이웃 방의 연결·충돌을 검증한다. 검증한 규칙을 바탕으로 실제 Room Template 제작을 진행한다.

## 현재 기준

- 방은 20×20 셀을 사용하며 출입구와 통과 조건은 [방 템플릿 제작 규격](Room_Template_Authoring_Guide.md)을 따른다. 현재 샘플은 단색 지형과 일부 기존 RuleTile 지형을 사용한다.
- [기존 Tile Palette](../../../Assets/@tempAssets/NovaDevs/2D%20Platformer%20-%20Skull%20Garden%20%20Tilesets%20Asset%20Pack/Tile%20Palette/)와 [GridTileGround](../../../Assets/Prefabs/Map/GridChunk/GridTileGround.asset)를 지형 그래픽 후보로 조사한다.
- 방과 내부 패턴은 별도 Tilemap을 사용할 수 있으므로 이웃 타일 판정과 방 경계의 표현을 실제 생성 결과에서 확인해야 한다. 콘텐츠 설치면 검사는 현재 셀 전체가 충돌하는 Grid 타입 지형을 요구한다.
- Cave 타일이 참조하는 원본 Sprite와 메타 파일이 현재 프로젝트에 없다. Cave 배경을 사용하려면 에셋과 참조 복구 가능성을 별도로 확인한다.

## 핵심 단계

1. **타일과 규칙 조사:** 기존 Palette와 RuleTile의 Sprite, 이웃 판정, Collider와 배치 용도를 확인한다. 바닥·벽·천장·모서리와 장식에 필요한 타일 및 빠진 경우를 정리한다.
2. **배치 방식 결정:** 고정 지형과 내부 패턴을 어떤 Tilemap에 배치할지 정한다. 지형 충돌과 그래픽을 같은 Tilemap으로 유지하는 방식과 분리하는 방식을 비교하고, 선택에 필요한 생성·검증 변경을 기록한다. 방 경계와 패턴 경계의 타일 연결 방식도 결정한다.
3. **대표 방 적용:** 단색 지형으로 이동 구조를 확인한 대표 방 1~2개에 기존 타일과 필요한 RuleTile 수정안을 적용한다. 인접 방과 패턴의 조합을 만들어 경계·모서리와 Collider를 확인한다.
4. **제작 규칙 확정:** 출입구 주변, 고정 지형, 내부 패턴, 배경과 장식의 배치 기준을 문서화한다. 장식은 우선 수동 배치를 기준으로 검토하고 필요한 경우에만 랜덤 배치 규칙을 설계한다.
5. **Room Template 확장:** 확정한 규칙으로 템플릿을 제작하고 카탈로그에 등록한다. 지형·충돌·통로가 변경된 템플릿은 기존 통과 검증 표시를 해제하고 해당 방향과 조합을 다시 확인한다.

각 단계가 끝나면 결과를 보고하고 다음 단계 진행을 기다린다.

## 검증 기준

- 대표 방의 바닥·벽·천장·모서리와 방 및 패턴 경계에서 타일의 모양과 빈틈을 확인한다. 서로 다른 Tilemap 사이의 연결은 실제 조합으로 판단한다.
- 실제 Collider와 콘텐츠 설치면 판정이 제작 규칙에 맞고, 출입구·착지면·필수 통로가 유지되어야 한다.
- 지형이나 충돌을 변경한 조합은 실제 Player의 이동·점프·대쉬로 해당 진입과 진출을 확인한다. 반복 검증이 많아질 경우 검증 범위를 먼저 확인받는다.
- Player 조작, 상태와 Console을 확인하고 가상 입력 장치와 콜백을 정리한다.
