# Chunk 콘텐츠 구조 검토 요청

현재 프로젝트의 Chunk 콘텐츠 설정과 생성 구조를 독립적으로 검토해 주세요. 코드와 에셋은 수정하지 말고, 발견 사항과 근거를 한국어로 보고해 주세요.

## 검토 범위

- 기준 변경: `c88bf270..dbad9927`의 Chunk 콘텐츠 설정 분리, 함정 설정 정리, Base·Variant 이전. 변경 전후 차이와 현재 소스를 함께 확인합니다.
- 주요 코드: `Assets/Scripts/Map/RoomTemplates/`의 설정·검사·선택·생성 코드와 `Assets/Scripts/Map/MapRuntime/RoomMapFactory.cs`, `RoomObjectives/`의 목표 연결 코드.
- 에셋: `Assets/Prefabs/Map/RoomTemplates/Base/`, `NovaVariants/`, `Assets/Prefabs/@Data/Map/`의 카탈로그와 맵 설정. 필요하면 연결된 프리팹과 테스트를 확인합니다.
- 참고 문서: `Docs/Map/Map_Code_Architecture_Guide.md`, `Docs/Map/Chunk_Generation/Room_Content_User_Guide.md`, `Docs/Map/Chunk_Generation/Work/Chunk_Generation_Code_Guide.md`. 문서의 설명이 소스와 맞는지도 확인하되 현재 소스와 에셋을 기준으로 판단합니다.
- 검토 전 `git status --short`로 작업 중인 변경을 확인합니다. 커밋된 변경과 미커밋 변경의 발견 사항을 구분하고, 기존 변경은 수정하거나 되돌리지 않습니다.

## 확인할 내용

1. Base가 공통 지형·출입구·설정 컴포넌트를 제공하고 Variant가 배경과 몬스터·아이템·함정·목표 후보를 설정하는지, 프리팹 상속과 Override 및 카탈로그 참조가 이를 유지하는지 확인합니다.
2. 몬스터·아이템 슬롯의 Inspector 설정이 이해하기 쉽고 각각 독립적으로 선택되는지, 일반 방·선택 방의 콘텐츠 역할과 설치면·공간 검사가 올바른지 확인합니다.
3. 슬롯·후보 식별자의 생성, 복제, 재정렬, 저장과 seed 재현성을 확인합니다. 설정 변경 후 과거 seed의 결과가 달라질 수 있는 점과 동일 설정에서의 재현성을 구분합니다.
4. 함정 후보의 활성화·비활성화와 공간·지지면 검사가 올바른지, 이전된 프리팹 참조와 직렬화 값의 손실이나 누락이 있는지 확인합니다.
5. 실제 생성된 몬스터가 목표로 전달되는 흐름, 적용 가능한 규칙 선택, 목표가 없는 경우, 문 잠금·개방과 이벤트 정리에서 오류 가능성을 확인합니다.
6. SOLID·OCP·DRY와 책임 분리, 코드 이해도, 테스트의 실질적인 누락을 검토합니다. 원칙 위반이라는 표현만으로 판단하지 말고 구체적인 문제와 더 단순한 개선 가능성을 설명합니다.

- 확인된 사실, 코드에서 추론한 위험, 확인하지 못한 사항을 구분합니다. 재현하지 못한 문제는 확정된 사실처럼 쓰지 않습니다.
