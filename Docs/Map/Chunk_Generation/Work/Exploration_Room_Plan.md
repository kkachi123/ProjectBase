# 탐사형 방 구조와 콘텐츠 배치 계획

## 목표

좌우로 지나갈 수 있는 방에 짧은 상층 우회 경로를 구성하고, 경로 선택이 아이템과 전투 배치로 이어지게 한다.

## 현재 조건

- 방은 20×20 셀이다. 좌우 출입구는 y `4~7`에 있으며 `Horizontal` Base는 양방향 통과와 상단 지형 변형을 제공한다. `NorthWest_Tiered`는 북쪽에서 서쪽으로 내려가는 다층 방이다.
- Player 이동 설정은 지상 속도 5, 공중 속도 4, 점프 힘 8, 대시 거리 5, 공중 대시 1회다. 점프·착지 가능 여부는 실제 충돌과 조작으로 확인한다.
- 주 경로는 좌우 이동과 하강으로 계획하며, 방은 출입구와 검증된 진입→진출 방향에 맞춰 선택한다. 새 Base 그룹과 Variant를 카탈로그에 추가하면 같은 seed의 방 선택이 달라질 수 있다.
- Goblin 설정의 `MaxTargetHeightDifference`는 1이다. 층이 나뉜 상황에서 인식·추적과 목표 처치 가능 여부를 확인해야 한다.

## 대표 방: 상층 우회 회랑

- **역할과 출입구:** 일반 주 경로 방. 서·동 출입구를 사용하고 서→동, 동→서 통과를 각각 확인한다.
- **이동 구조:** 아래층은 양쪽 출입구를 잇는 기본 통로다. 양쪽에서 올라갈 수 있는 짧은 단차를 거쳐 상층 발판과 보상 공간에 접근하고, 아래층으로 돌아올 수 있게 한다. 상층 접근에 벽 점프나 대시를 필수로 요구하지 않는다.
- **구분:** 기존 `Horizontal`의 상단 변형은 선택된 패턴에 따라 달라진다. 이 방의 상층 접근로는 보상 접근을 위한 고정 지형이므로 별도 Base로 제작한다.
- **컨셉:** 숲에 묻힌 폐허 회랑. Nova 에셋의 지형과 배경으로 상층 발판의 존재와 보상 위치를 알아볼 수 있게 한다. 장식은 출입구·발판·몬스터를 가리지 않도록 한다.
- **콘텐츠 구상:** Variant에 아래층의 일반 몬스터 후보 슬롯과 상층의 아이템 후보 슬롯을 각각 둔다. 몬스터는 진입 직후 피할 수 없게 배치하지 않고 대응 공간을 확보한다. 아이템은 현재 확률 선택을 사용하므로 나오지 않는 경우에도 지형만으로 상층 탐색이 가능하다. 함정은 동선·가시성·회피 공간을 확인한 뒤 적합할 때만 배치한다.

```text
       상층 발판 ── 아이템 후보 ── 상층 발판
          ↗                         ↘
서쪽 입구 ───── 아래층 기본 통로 ───── 동쪽 출구
                  몬스터 후보
```

그림은 동선 개념도다. 발판 좌표·높이·배경과 콘텐츠의 최종 위치는 제작 및 Player 검증 후 결정한다.

## 제작 범위와 순서

1. 대표 Base 1개와 이를 상속한 Nova Variant 1개를 제작한다. Base에는 고정 지형·출입구·통로와 설정 컴포넌트, Variant에는 배경과 콘텐츠 후보를 둔다.
2. 우선 고정 지형과 기본 통로를 검증하고 `Passages`에 실제 통과한 방향만 기록한다. 상층 이동의 성공과 복귀를 확인한 뒤 검증 표시를 설정한다.
3. Variant에 몬스터·아이템 후보를 설정하고 설치 조건, 등장 유무와 각 방향에서의 접근·전투를 확인한다. 함정을 추가한다면 함정의 유무와 콘텐츠 조합도 확인한다.
4. 검증된 Variant를 카탈로그에 등록하고 여러 seed의 맵 생성·연결과 같은 설정·seed의 재현성을 확인한다. 대표 방의 결과를 보고 다른 Base 또는 기존 방의 콘텐츠 조정 범위를 정한다.

## 완료 기준

- 대표 Base 1개와 Nova Variant 1개가 카탈로그에 연결되고, 서→동과 동→서로 실제 Player가 통과한다.
- 양쪽 접근 방향에서 상층 보상 공간에 도달하고 아래층으로 복귀할 수 있다. 아이템이 생성된 경우 실제 획득을 확인한다.
- 몬스터 생성·미생성 시 동선과 대응 공간을 확인한다. 함정을 배치한 경우 생성·미생성의 통과와 가시성·회피 공간도 확인한다.
- 방 경계·RuleTile 표시, 설치 조건과 맵 연결을 확인하고 같은 설정·seed의 결과가 재현된다. 미확인 조합은 진행 현황에 기록한다.
- 실제 Player 조작은 Title → InGame에서 진행하며 반복 검증 범위가 커지면 횟수를 안내하고 확인받는다.
