# Chunk 내부 생성 진행 현황

선택된 방의 내부 조합, Room Template과 그래픽 작업의 현재 상태를 기록한다. 전체 요약은 [맵 작업 진행 현황](../Map_Progress.md), 제작 기준과 코드 설명은 [Chunk 내부 생성 문서 안내](README.md)를 참고한다.

체크는 해당 항목에 적힌 범위의 구현과 검증을 뜻한다. 일부 방이나 샘플에서 확인한 결과는 범위를 함께 표시하며 다른 조합에 대한 검증으로 확대하지 않는다.

## 완료한 기본 단계

- [x] **템플릿 제작 규격:** 20×20 방, 네 방향 출입구·고정 지형·보호 영역·슬롯·마커 기준을 정하고 샘플의 기록된 17개 통과 방향을 실제 Player로 확인했다. [제작 규격과 검증 범위](Work/Room_Template_Authoring_Guide.md).
- [x] **내부 지형 선택 기능:** 변형 영역의 패턴 또는 빈 패턴, 지정된 확률 셀을 seed로 선택하고 계획대로 적용한다. `sample.horizontal`에서 패턴·확률 셀 네 조합의 양방향 통과를 확인했다. [코드 구조](Work/Chunk_Generation_Code_Guide.md).
- [x] **콘텐츠 슬롯 기본 기능:** 슬롯의 설치 공간·지지면을 확인하고 후보 또는 빈 상태를 가중치로 선택한다. 현재 방 역할에 따라 후보 종류를 구분하며 실제 생성·획득 검증 범위는 아래 5번을 참고한다.
- [x] **지형 그래픽 시제품:** NovaDevs 기반 RuleTile과 공통 그래픽 Tilemap을 구현하고 대표 방·패턴·경계와 Player 이동을 확인했다. 모든 방 조합과 조명에 대한 미관 검증은 아니다. [그래픽 설계](Work/NovaDevs_Level_Art_Design.md).
- [x] **배경·장식 제작 규칙:** 데모 씬과 대표 프리뷰를 참고해 배치·표시 순서와 확인 기준을 정리했다. [제작 규칙](Work/Room_Art_Authoring_Guide.md).

## 남은 단계

1. [x] **Room Template 사용 관계 조사:** 기본·Nova 카탈로그, 패턴·타일과 씬·테스트의 정적 참조를 조사하고 폴더 구분 기준안을 정리했다. 결과와 조사 범위는 [사용 관계 조사](Work/Room_Template_Inventory.md)를 참고한다.
2. [x] **Room Template 정리:** 방·패턴·공용 에셋의 폴더를 역할별로 정리하고 테스트·문서 경로를 갱신했다. GUID와 카탈로그·씬 참조를 확인하고, 두 설정의 대표 seed별 이동 전후 계획을 비교했다. 맵 EditMode 테스트 57개가 통과했다.
3. [x] **대표 Base·Nova Variant 검증과 선택 방식 결정:** `Base/Horizontal`의 Variant에서 지형·검증 표시 상속과 네 가지 내부 조합의 맵 생성을 확인했다. 패턴·확률 셀을 모두 적용한 방에서 Player의 좌우 통과를 확인했다. Base 사본 변경 시 Variant에 상속되지만 검증 표시는 자동 해제되지 않는다. 방 선택은 조건에 맞는 Base 그룹을 먼저 고르고 Variant를 고르는 방향으로 정했다. 맵 EditMode 테스트 59개가 통과했다.
4. [x] **Base와 Nova Variant 구성:** Base 그룹과 Variant를 순서대로 고르는 기능을 구현했다. 기존 Base를 우선 활용해 기존 Nova 방 14개에 대응하는 Variant와 닫힌 방·분기용 Variant 3개를 만들고, 역할이 다른 시작·Goal·선택 방용 Base 5개를 추가했다. 시제품에 대응하는 방의 실제 Player 이동·목표 연결 16개를 확인했다. 17개 Variant만 담은 임시 카탈로그의 1,000개 seed 계획과 20개 맵 생성을 확인했으며 맵 EditMode 테스트 63개가 통과했다. 분기용 Variant의 화면에서 발견한 배경 이음새와 장식 반복은 7번에서 수정한다.
5. [x] **방 역할별 콘텐츠 배치:** 최종 방 역할에 따라 일반 경로 방은 일반 몬스터·아이템, 선택 방은 아이템·엘리트 몬스터 후보를 사용한다. 대표 `WestSouth` Base와 상속 Variant에 Goblin·아이템 슬롯을 설정했다. 생성 맵에서 Goblin의 추적과 점프 통과, 일반 방 아이템 획득·통과와 선택 방 아이템 획득·복귀를 실제 Player로 확인했다. 다른 일반 방은 아직 콘텐츠 슬롯이 없으며, 엘리트 몬스터는 프리팹 제작 후 연결하고 생성·이동을 검증한다. 맵 EditMode 테스트 66개가 통과했다. 세부 조건은 [Base·Nova Variant 작업 지침](Work/Room_Tile_Visual_Plan.md)을 따른다.
6. [x] **Nova 카탈로그 전환:** 기존 설정과 카탈로그의 GUID를 유지하면서 Variant 17개와 Nova 지형 그래픽으로 전환하고 중복 시제품 설정·카탈로그를 제거했다. 1,000개 seed의 계획과 씬·에디터·테스트 참조를 확인했으며 맵 EditMode 테스트 67개가 통과했다. Title에서 실제 Run을 시작해 방 16개와 Player를 생성하고 시작 방의 서쪽 출구를 통과했다. Base는 Variant의 부모로 유지한다.
7. [x] **그래픽과 내부 조합 확인:** `Junction_Down`, 두 가로 방과 `Down_ForestStep`의 수관 겹침을 조정하고 분기 방과 하강 방의 줄기·수풀 배치를 바꿨다. [분기 방 수정 결과](Work/Images/NovaVariant_JunctionDown_Adjusted.png)는 seed `0`의 생성 맵을 임시 카메라와 전역 조명으로 촬영했다. 변형 지형을 사용하는 두 가로 Variant의 패턴·확률 셀 네 조합과 대표 인접 방을 렌더링하고 맵 EditMode 테스트 67개가 통과했다. 충돌 지형은 바꾸지 않았으며 이번에 실제 Player 이동은 반복하지 않았다. 모든 방 연결과 실제 게임 조명의 가독성은 검증하지 않았다.

   카탈로그의 Variant 17개에서 고정 지형과 배경 장식의 지면 접촉을 추가 점검했다. 장식이 있는 16개 방에서 나무·건축물·수풀의 바닥 기준점을 약 0.1유닛 겹치도록 조정했다. [수정 후 생성 화면](Work/Images/ShrineGroundOverlap.png)은 임시 카메라와 조명으로 확인한 결과다. 패턴·콘텐츠의 모든 실제 플레이 조합을 검사한 것은 아니다.

8. [ ] **방 구조와 함정 제작·배치:** 높이가 다른 발판과 통로를 함정과 함께 검증하고, 준비된 함정을 대표 방에 확률 배치한다. 단계마다 결과를 보고하고 다음 지시를 기다린다. 세부 조건은 [Base·Nova Variant 작업 지침](Work/Room_Tile_Visual_Plan.md)을 따른다.

   - [x] **화살 함정 조사·설계:** Bullet 프리팹과 기존 발사·풀·피해 코드를 조사하고 발사 조건·방향·속도·피해·작동 중지 조건을 정했다. 실제 발사·피해 검증은 다음 단계에서 수행한다. [설계](Work/Room_Tile_Visual_Plan.md#함정-제작배치-계획).
   - [x] **화살 함정 프리팹 제작:** 투명 발사기와 `CircleBullet` 외형의 별도 투사체를 만들고 발사기별 풀을 연결했다. 독립 Play 환경에서 좌우 발사, 반복 발사, Player 피해, 지형 충돌, 몬스터·무관한 Trigger 무시, 수명과 비활성화·파괴 정리 및 인스턴스 재사용을 확인했다. Player는 가상 키보드로 이동했고 체력이 10에서 9로 감소했다. [외형 프리뷰](Work/Images/ArrowTrap_IndependentPreview.png)는 독립 씬에서 가독성을 위해 발사 간격 0.5초·속도 1로 조정한 화면이다. 실제 맵과 최종 화살 외형은 아직 확인하지 않았다.
   - [x] **대표 방 배치:** `Base/NorthEast`의 서쪽 벽에 오른쪽으로 발사하는 후보를 기본 비활성 상태로 배치했다. 상속된 `Arrival_ShrineAtrium`에서 함정이 꺼진 경우와 켜진 경우 모두 실제 Player의 북→동 통과를 확인했으며, 켜진 경우에는 투사체를 점프로 피하고 체력 10을 유지했다. 수명 3초로 발사 범위를 제한하고 맵 EditMode 테스트 67개가 통과했다. [임시 화면](Work/Images/ArrowTrap_NorthEast_Preview.png)은 Variant에 RuleTile·임시 카메라와 조명을 적용한 독립 방이다. 실제 생성 맵과 다른 방 조합은 아직 검증하지 않았다.
   - [x] **랜덤 배치 연결:** 검증한 `NorthEast` 후보를 생성·빈 상태 1:1 가중치로 등록하고, 선택·검증·방 생성에 연결했다. 1,000개 seed에서 생성 570회와 빈 상태 586회를 확인했으며 맵 EditMode 테스트 71개가 통과했다. 실제 생성 맵의 seed `8`에서는 화살 회피 후, seed `2`에서는 빈 방 통과 후 각각 동쪽 방 Goblin의 Player 추적을 확인했다. 화살과 Goblin이 같은 방에 배치되는 조합은 아직 없다.
   - [ ] **다른 함정 확장:** 준비된 함정별 동작과 설치 조건을 검증한 뒤 맵에 연결한다.
     - [x] **Spikes 독립 동작:** Player가 접촉할 때 피해 1을 주고, 계속 닿아 있는 동안 중복 피해를 주지 않도록 했다. 실제 Player의 접촉·유지·이탈·재진입과 몬스터 제외를 확인했다. Sprite의 투명 영역에 맞춰 Trigger를 조정했고, 복수 Collider와 함정 재활성화는 별도 테스트 대상으로 확인했다.
     - [x] **Spikes 대표 방 배치:** `Base/NorthWest`의 바닥에 기본 비활성 후보를 배치하고 `Arrival_RuinedGallery`의 상속을 확인했다. Title에서 시작한 seed `3` 맵에서 후보가 꺼진 경우와 켜진 경우 모두 Player의 북→서 통과를 확인했다. 켜진 경우 가시를 점프로 피하고 체력 10을 유지했다. [실제 게임 화면](Work/Images/Spikes_NorthWest_InGame.png)에서 바닥과 Sprite의 위치를 확인했다.

     - [x] **Fire 대표 방 배치:** `Base/WestSouth`의 바닥에 기본 비활성 후보를 두고 `Down_ForestStep`의 상속을 확인했다. Title에서 시작한 seed `270`의 아이템 배치 맵에서 후보가 없는 경우와 있는 경우 모두 Player의 서→남 통과를 확인했다. 후보가 있을 때는 불이 꺼질 때 지나가 체력 10을 유지했다.
