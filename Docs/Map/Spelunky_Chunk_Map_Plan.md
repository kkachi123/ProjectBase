# 스펠렁키식 청크 맵 재설계 계획

## 목표와 결정 사항

방 유형별 템플릿으로 시작점부터 출구까지 이어지는 맵을 만들고, 템플릿 내부의 지형과 콘텐츠를 조합한다. 제작 규칙과 클래스의 책임을 명확히 하여 제작자가 생성 결과를 이해하고 문제를 재현할 수 있게 한다.

- 진행 방식은 좌우 이동·하강 중심으로 정한다.
- Chunk별로 상하좌우 중 필요한 출입구 조합을 지정한다.
- 방 템플릿 규격과 고정 지형의 연결을 마련한 뒤, 템플릿 내부의 패턴·확률 셀·콘텐츠를 조합한다.
- Base 프리팹에 출입구·충돌 지형·변형 영역과 콘텐츠 슬롯을 두고, 콘셉트별 Prefab Variant에 배경과 장식을 구성한다. 지형 구조가 다르면 별도 Base로 관리한다.
- 일반 경로 방에는 일반 몬스터와 아이템을, 선택 방에는 아이템과 엘리트 몬스터를 배치한다. 엘리트 몬스터는 제작 후 연결한다.
- 함정은 방에 지정한 위치와 영역에서 후보 또는 빈 상태를 확률적으로 선택한다. 필수 경로의 통과 가능성을 유지한다.
- 맵 설정에 난이도별 ScriptableObject를 지정해 일반 몬스터·엘리트 몬스터·아이템·함정의 출현 확률을 조절한다.
- 맵 설정에 콘셉트별 Variant 카탈로그와 지형 그래픽을 직접 지정한다.
- 필수 경로는 현재 Player의 이동·점프·대쉬로 통과할 수 있어야 한다.

## 참고한 스펠렁키 구조

Spelunky Classic의 방 격자 경로, 방 유형과 템플릿 내부의 고정 지형·확률 타일·장애물 패턴 조합을 참고한다. [경로 생성 분석](https://tinysubversions.com/spelunkyGen/), [방 내부 생성 분석](https://tinysubversions.com/spelunkyGen2/), [공식 Classic 페이지](https://www.spelunkyworld.com/original.html).

## 맵 생성 구조

```text
Chunk 템플릿·카탈로그와 설정
    → 주 경로·Chunk 선택 → 내부 지형·콘텐츠 선택
    → 계획 검증 → 씬 생성 → Player·Goal과 Run 연결
```

- **맵 조합:** 기본 4×4 격자에서 위쪽 시작점부터 좌우 이동과 하강으로 주 경로를 만들고, 지정된 카탈로그에서 조건을 충족하는 방 Variant를 선택한다. 경로 밖은 닫힌 방으로 채우며 검증된 후보가 있으면 막다른 선택 방을 최대 하나 연결한다. 연결된 출입구는 위치와 폭이 같아야 하고 연결하지 않은 면은 닫는다.
- **Chunk 내부:** 20×20 셀 템플릿의 고정 지형을 유지하면서 보호 영역 밖에 지정된 패턴과 확률 셀을 선택한다. 콘텐츠는 설치면과 공간 조건을 검사한 슬롯의 후보와 가중치에 따라 배치한다. 출입구·필수 통로·착지면은 변형으로 막히지 않아야 한다.
- **생성과 Run:** 계획과 Unity 씬 생성을 분리한다. 계획 실패 또는 생성 실패 시 사유를 반환하고, 새 맵이 성공적으로 생성된 뒤 기존 맵을 교체한다. 에디터 미리보기와 런타임은 공통 생성 흐름을 사용한다. 캐릭터 FSM의 상태 구성은 맵 생성기가 담당하지 않는다.
- **재현과 검증:** 같은 설정·카탈로그·코드와 seed로 같은 계획을 재현한다. 경로, 내부 지형, 콘텐츠 선택의 난수 흐름은 분리한다. 출입구와 제작 데이터를 자동 검사하고, 실제 Player의 통과·착지와 필요한 조합은 별도로 확인한다.

현재 구현 범위와 각 단계의 완료 여부는 [맵 작업 진행 현황](Map_Progress.md)에서 확인한다. 상세 구조와 제작 기준은 [맵 생성 코드 안내](Map_Code_Architecture_Guide.md), [맵 조합](Map_Assembly/Map_Assembly_Code_Guide.md), [Chunk 내부 생성](Chunk_Generation/README.md)을 참고한다.
