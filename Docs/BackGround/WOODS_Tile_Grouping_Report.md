# WOODS Tile 1단계 분석 결과

## 조사 범위

- 원본 Sprite sheet: `Assets/@tempAssets/karsiori/TileMap/Tiles/Tilesheet - WOODS.png`
- Tile 에셋: `WOODS_0`~`WOODS_87` 총 88개
- 모든 Tile은 32×32 Sprite를 참조한다.
- 원본 Tile과 Palette는 변경하지 않았다.

## 분석 방법

각 Sprite를 3×3으로 나누어 중심 영역의 대표 색과 주변 여덟 영역을 비교했다. 이 결과는 연결 후보를 찾는 보조 자료이며, 색상만으로 지형의 의미를 확정하지 않는다. 특히 경사·그림자·장식이 있는 타일은 시각적 연결성을 함께 검토했다.

## 분리 기준

1. **인접 연결성** — 내부·변·코너가 같은 토양과 잔디 윤곽을 연속적으로 구성하는지 본다.
2. **방향성** — 대각 경사는 직교형 RuleTile의 여덟 방향 규칙과 별도로 다뤄야 하므로 분리한다.
3. **재사용성** — 하나의 RuleTile을 반복해서 칠했을 때 자연스럽게 이어지는 타일만 같은 그룹에 넣는다.
4. **예외 처리** — 단독 오브젝트·플랫폼 끝·기둥 형태는 연결 지형으로 오인될 수 있어 자동 생성 대상에서 제외한다.

## 2단계로 넘길 제안

1. 먼저 `WOODS_Ground_Core`와 `WOODS_Ground_Border`를 하나의 **직교형 지면 RuleTile 후보**로 검토한다.
2. `WOODS_Ground_Slope`는 별도 그룹으로 유지하고, 일반 RuleTile로 만들지 또는 수동 Tile로 유지할지 결정한다.
3. `WOODS_Platform_And_Special`은 이번 RuleTile 생성 대상에서 제외한다.

## 남은 확인 사항

- `WOODS_Ground_Core`의 네 타일이 동일 지형의 변형인지, 서로 다른 지형인지 확인
- 직교형 지면 그룹에서 필요한 코너·역코너가 모두 있는지 확인
- 경사 그룹에 적용할 Tile 규칙 방식 결정

## 1단계 완료 판정

파일 조사, 역할 기록, 후보 그룹화, 제외 목록 작성은 완료했다. 다음 단계는 위 제안을 검토하여 실제 RuleTile 대상 그룹과 제외 범위를 승인하는 것이다.
